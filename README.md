# Aviss

App Android (tablet) para veterinarios que hacen tacto reproductivo en tambos. Funciona sin conexión: importa un Excel de Dairy Comp, trabaja con el bastón RFID Tru-Test XRS2 sobre SQLite y exporta un Excel para volver a Dairy Comp.
